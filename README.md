# 台灣性別平等教育承辦人skill

**又名：部上再也不用擔心承辦人陣亡了skill**

協助臺灣性別平等教育承辦人處理法規函釋、案件流程、當事人保護、支持服務、教育處置、性平會會務，以及面對不合法要求時的程序異議與後續簽辦。目前工作模組及資料以**大專校院**為主。

本儲存庫提供完整原版及Notebook適配版。完整原版保留法源、PDF、檢索工具與範本；Spark／Notebook版將法源移到48份Notebook來源，保留7檔承辦技能。別名是維護者的幽默命名，不是安全保證或實證因果結論。

## 這個技能處理什麼

- **案件與程序：** 初接觸、管轄、通報、收件受理、調查行政、議處、通知及救濟；跨校、身分異動與三法分流。
- **保護與支持：** 區分現場救援、法定正式保護措施、被害人需求支持及調查屬實後的行為人教育處置。
- **會務：** 會前材料、名冊與權限、逐案出席迴避、表決、會中異議、真實紀錄與會後執行。
- **不合法要求：** 核對提出者的權限與依據；被要求照辦時，提供適用身分下的簽註、逐級陳核與必要監督銜接。
- **法源與年度業務：** 原文查找、歷史與現行適用區分、前後函、資料品質、年度計畫、預算、孕產支持及交接。

原版內容包括24個參考模組、14組範本、18份法規／指引JSON、23份年度函釋轉錄、354筆函釋索引、43條已整理關係、148條文字連結候選及27項品質／重號問題。354筆含347筆年度原稿條目及7筆查閱摘要，不等於354份經逐字核真的公文原件。

## 安裝完整原版

1. 下載完整原版ZIP，解壓至名為`taiwan-gender-equity-education-officer`的資料夾，完整保留所有子目錄。
2. 在支援技能的環境選取SKILL.md；其他環境須確認能按需讀取同一資料夾的模組及來源，不假設只有主指令也能完整運作。
3. Python檢索工具需要Python 3.10以上。能否執行由平台環境決定；只有讀到檔案名稱不算資料掛載成功。
4. 依實際本校資料填寫assets/school-profile.example.yaml所列欄位。未確認的組織、權限及決議保持未確認。
5. 先以合成題確認來源可讀，再使用實際業務資料。

技能是行政幕僚工具，不代作法定決議、事實認定或對外通報。資料查到不等於現行有效；法律義務、期限及處分依據按問題核對官方有效原文。
