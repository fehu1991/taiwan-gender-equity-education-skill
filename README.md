# 台灣性別平等教育承辦人skill

### aka：部裡再也不需要擔心承辦人陣亡了skill

給臺灣大專校院性平承辦人量身設計的工作技能，整合了相關法規、以及2004–2026年中的函釋、案件程序與公文範本。

從收件通報、性平會會務到跨校處理、當事人支持與主管要求，協助承辦人查資料、判斷程序、整理簽辦。

## 技能能做什麼

| 工作 | 內容 |
|---|---|
| 案件程序 | 收件、通報、管轄、受理、調查行政、議處、通知與救濟；跨校案件及身分異動。 |
| 性平會會務 | 會前資料、委員資格、出席與迴避、表決、會議紀錄及後續執行。 |
| 保護與支持 | 當事人保護、被害人需求、支持服務與行為人教育處置。 |
| 公文與承辦應對 | 簽辦、通知、報告、程序異議；面對不合法要求時的書面回應。 |
| 法源與年度業務 | 法規函釋、前後函關係、年度計畫、預算、孕產支持與交接。 |

原版收錄 **24個工作模組、14組範本、18份法規／指引、23年度函釋及354筆函釋索引**。

## 安裝

### 原版

下載原版ZIP，在使用的平台掛載完整技能包。若採資料夾安裝，解壓到 `taiwan-gender-equity-education-officer`，保留子目錄，入口為 `SKILL.md`。

### Gemini Spark＋Notebook版

**台灣性別平等教育承辦人殘缺版skill**  
又名：**gemini spark可能會加速承辦人陣亡skill**

<img width="1431" height="1422" alt="圖片" src="https://github.com/user-attachments/assets/f81d80e2-4406-441d-a42e-3eee9a575e5d" />

Spark上傳完整資料遇到檔案數限制，因此改成7檔技能搭配外部Notebook。這版將法源移入Notebook，省去原版的本地程式檢索工具。

1. 下載並解壓「Spark＋Notebook整包」。
2. 在Spark的「技能 → 上傳」，選擇包內的 `Spark技能.zip`。
3. 建立Notebook，將 `Notebook法源` 資料夾裡的48份文件匯入。
4. 把 `Notebook指令.md` 的設定文字貼入Notebook指令欄。
5. 開啟Spark任務，選取技能，再用「新增Notebook」掛載剛建立的法源庫。

包內有逐步安裝說明。**外層整包先解壓；送進Spark的是裡面的「Spark技能.zip」。**

### 第一份：Grok出題，收件後72小時

私立大學同時遇上研究生兼教學助理傳送性暗示訊息、實習醫院指導人員涉案、醫院已自行調查、導師延遲轉知、轉學跨校、匿名檢舉、家長和解及群組洩漏。主管還要求承辦先訪談、援引舊函、預寫救濟與併案處理。

### 測試心得與模型選擇

- **首選ChatGPT Astra快思：** 在雙題測試中各評審給分均達94分以上，與最高模式相近，性價比最好；缺點是回答較慢。
- **Grok專家：** 指令遵循與答題速度表現好，第一份題本得分最高。
- **Claude Opus 5 High：** 速度與準確度穩定，主要考量是使用額度。
- **Gemini Spark：** 掛Notebook後仍落後，測試中出現自行補造日期，現階段不推薦擔任性平業務助手。
- **ChatGPT Luna：** 題目A表現明顯較弱，性平業務優先選Astra快思。
